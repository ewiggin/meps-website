/ POR QUÉ

Tus datos viven en hojas de cálculo. Tus aplicaciones necesitan una API.

La lista de precios, el registro de clientes, el inventario, las ventas del año pasado. Toda empresa tiene datos en Excel que una web, una herramienta interna o una integración necesitan leer, y convertirlos en un backend de verdad suele suponer una base de datos, un esquema, una API y semanas en la cola de desarrollo.

instantDB se salta todo eso. Arrastra el archivo y obtienes una tabla con sus columnas detectadas, endpoints para leer, filtrar, insertar, actualizar y borrar filas, y documentación interactiva para quien tenga que usarla. Cuando cambien los datos, vuelve a subirlo.

/ CÓMO FUNCIONA

Del archivo al endpoint en tres pasos.

Todo ocurre en una interfaz web: sin línea de comandos y sin SQL. Los desarrolladores tienen una API REST estándar y una especificación OpenAPI; el resto del equipo, una tabla que puede consultar.

01

Sube

Arrastra un CSV o un Excel a la página. Elige una hoja o importa cada hoja como un dataset independiente. Admite CSV con cualquier separador.

02

Obtén una tabla

Las columnas se detectan y se nombran solas, y cada fila recibe un id. Recibes un código de propiedad que protege el dataset frente a cambios.

03

Usa la API

Los endpoints funcionan al instante y están documentados en Swagger UI. Conecta tu web, tu app, tu hoja de cálculo o tu herramienta de automatización.

/ API

Una API REST de verdad, no una exportación.

Leer y buscar es libre; escribir exige el código de propiedad del dataset, así que un endpoint público de lectura nunca se convierte en uno público de escritura. El límite de peticiones viene activado por defecto.

/ FUNCIONES

Más que un CRUD.

Con los datos dentro, instantDB te da las piezas que normalmente cuestan un sprint cada una: combinar tablas, reaccionar a cambios, recoger filas nuevas y ver los números.

  1. JOINS

    Combina datasets

    Un editor visual para unir varias tablas por sus columnas, agrupar y ordenar el resultado, y guardarlo con un nombre para abrirlo otra vez cuando quieras.

  2. WEBHOOKS

    Reacciona a cambios

    Avisa a tus sistemas cuando se insertan, actualizan o borran filas, o cuando se sube un dataset. Con registro de entregas y envíos de prueba.

  3. FORMULARIOS

    Recoge filas

    Crea un formulario para cualquier dataset, elige qué campos mostrar y compártelo. Cada envío es una fila nueva, ya sea público o privado.

  4. GRÁFICOS

    Ve los números

    Grafica cualquier dataset o resultado de un join, y consulta estadísticas por columna sin volver a exportar nada a Excel.

/ DETALLES

Tus servidores

instantDB se instala en tu infraestructura. Tus datos nunca pasan por la nube de un tercero.

SQLite o Postgres

Un único archivo SQLite para empezar, o conéctalo a tu PostgreSQL cuando crezcan los datos.

Documentada

Swagger UI y una especificación OpenAPI, listas para generar un cliente tipado en el lenguaje que use tu equipo.

Escritura protegida

Los cambios en filas, webhooks y formularios exigen el código de propiedad del dataset, y todos los endpoints limitan las peticiones.
